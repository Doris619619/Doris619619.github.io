# LiveNest Sans SC

按用户要求，从 `D:/Repo/LivePilot-v2/src/app/fonts/livenest-sans-sc.woff2` 原样复用网页端字体，不使用桌面客户端字体，也不修改 LivePilot-v2。

来源为 Noto Sans SC 的 LiveNest Sans SC 子集（100–900 可变字重），约 1.87 MiB。保留 GB2312、拉丁字符、标点和 LivePilot 网页常用字形；少量生僻字通过 Microsoft YaHei UI、PingFang SC、系统无衬线回退。

网站通过同源 @font-face、font-display: swap 及 preload 加载这个文件，不需要请求 Google Fonts 获取界面字体。文学正文使用的 Noto Serif SC 独立保留。
