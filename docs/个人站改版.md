# 个人站改版

## 页面与视觉

首页保持既有头像、居中大开场与动画布局。开场之后用三个自然段讲清个人背景、研究兴趣和生活，包含电路板研究、机器人、开源创作、乒乓球与写作；再用一条带图标的纵向时间线呈现精选经历，替代原来零散的研究、写作区块。关于页仅呈现技能、志愿服务、抖音图片和联系信息，移除重复个人叙述、研究工作教学与教育经历。

作品页按“研究”和“产品与工程实践”分组。桌面以较窄的章节说明列和主要阅读列组织内容；手机按章节、项目的顺序纵向阅读。GRACE 作为代表性研究，直接展示论文录用、第 5 作者、个人工作和项目结果，其他项目描述问题与个人贡献，完整技术资料在详情页。项目时间与发表年份分开，所有关键信息集中在同一阅读列。

项目标题含解释性短标题，避免只展示缩写。取消原来的整行覆盖链接，保留可分别聚焦的标题、论文页面、项目报告与详情入口；站内入口使用右箭头，公开资料使用外链箭头。项目截图仅在有真实素材的详情页展示，不使用大面积卡片底色与阴影。

主导航：首页、作品、手记、荣誉、关于。荣誉是独立页面，从首页的封面入口、主导航、关于、页脚与获奖文章可达。手机以非模态菜单提供全部主导航，Escape 关闭并把焦点归还菜单按钮。

内容区 1040px，文章 700px；正文 16px，文学原文 18px / 1.95 行高，项目标题桌面 22px、手机 20px。界面复用 LivePilot-v2 网页的 LiveNest Sans SC，保留大开场的原有布局。细线负责分组，玫瑰色用于强调和交互。取消旧项目卡片、大面积联系区和无功能分类栏。页面内容默认可见，不依赖滚动入场才能读到。

原轨迹页已并入首页：保留横向年度导航、分年标题与纵向事件线，按 2026、2025、2024 倒序排列。手机年度导航和事件均纵向排布。补齐升途教育授课经历、研究项目时间、ITSO 参数兼容与 Cherry Studio 接入信息。独立页面与入口取消，旧地址按语言与年份锚点转到首页；仅保留不参与索引的兼容重定向文件。

首页轨迹参考用户提供的 Karpathy 页面：日期、时间线、图标、说明四者对齐，按较新经历优先，USTF 使用用户确认的 2026.09，深圳市大数据研究院使用 2026.06 至今。港中深、深圳市大数据研究院、RoboMaster、伯克利与抖音使用官网标识，ITSO 使用用户指定的 GitHub 团队头像，教学保留电路图标。各项可进入已有详情页面，机构标识仅作装饰，标题提供完整名称。

## 内容与双语

中文默认，英文路径增加 `/en/`；语言切换保持当前页面与有效锚点，语言选择通过 URL 表达。主题跨页面保存，存储不可用时保持当页可用。

八项荣誉按 2026、2025、2024 年倒序展示，各年按月份倒序；每条保留学术与竞赛、写作与影像、体育类别标签。正式名称与奖项等级分别保存，不用奖杯装饰替代事实。已有证书作为缩略预览与独立链接，不作为文字背景。《灵语》使用用户提供的 2025 夏季刊封面，封面不充当证书；获奖说明与阅读原文入口集中在荣誉页，首页时间线移除对应的获奖事件。

《未选择的路》保留全部中文段落，中文写作日期 2025.01 与荣誉日期 2025.04 分开。英文页面只翻译标题、简介、导航与荣誉说明，正文标注为中文原作。全运会 81.50 小时志愿服务列为活动，不作为第九个奖项。

教育资料不展示 GPA。研究标题先解释具体问题，GRACE 缩写作为补充身份信息。GRACE 标明 DAC 2026 录用和第 5 作者；LLM × PCB 标明 AAAI 2027 在投。RoboMaster 的 GitHub 链接准确标为个人主页。仅使用已有的项目描述和指标。

## 实现与兼容

构建时生成 22 个 HTML（11 个页面 × 2 种语言），以及 404、RSS、sitemap、robots.txt。页面正文、导航和 metadata 在静态 HTML 内，客户端脚本只增强交互。无新增后台服务或生产环境迁移。

旧文章查询参数优先于 `#top` 迁移；首页旧栏目、项目锚点分别指向新页面。新链接全部使用独立目录 URL，适配 GitHub Pages 直接刷新。更新导航和内容时必须同时检查双语链接、站点地图与 RSS。

现有 `typecheck` 命令改为真实 JavaScript 语法检查并明确说明不提供静态类型分析。测试自动构建再验证页面、链接、奖项关联和原文摘要。

## 字体来源

`assets/fonts/livenest-sans-sc.woff2` 与 LivePilot-v2 网页源文件 SHA-256 一致：`f1121e7ef2838d3cbce718ce794fd3bf3da5e5707de07d34df3cbbed9801495c`。使用 100–900 可变字重，保留完整 OFL 许可；仅复制字体资产，未修改 LivePilot-v2。普通界面文字与中英文开场使用同一字体，文学阅读仍保留 Noto Serif SC。

项目日期来自现有简历：GRACE 为 2025.09—2025.12，LLM × PCB 沿用此前确认的 2025.12—至今，RoboMaster 为 2025.07—至今。VR-GS 只标已知的 2025 夏，不将课程学期推断为项目精确起止月份。项目列表、首页精选与详情共用日期数据，论文年份单独展示。两份简历对 LLM 项目结束时间存在差异，已向用户询问；未确认前沿用本轮已批准的进行中状态。

- [Andrej Karpathy](https://karpathy.ai/)：用户指定的首页时间线参考，只借鉴日期、图标与经历说明的排布。
- [Jon Barron](https://jonbarron.info/)：借鉴身份介绍、论文身份与成果证据相邻的组织方式。
- [Brittany Chiang](https://brittanychiang.com/)：借鉴章节说明与阅读列的分工，以及个人职责的具体叙述；保留本站多页面结构。
- [Shu Ding](https://shud.in/)：借鉴自然段个人叙述，让背景、兴趣与经历连贯。
- [Innei](https://innei.in/en)：沿用用户已确认的大开场和轻盈氛围。

上述网站已在浏览器实际查看。仅参考内容层次与排版原则，未复制第三方个人内容、图片或源代码。相关编辑摘要维护在 `content/portfolio.js`，分组与简介布局由 `src/portfolio.js` 复用。


桌面鼠标改用 Cuberto Mouse Follower 1.2.1 与 GSAP 3.15.0，本地托管、首次鼠标移动后加载。默认小光点、移动时轻微形变、链接柔和玫瑰色反馈；只有开场社交按钮使用磁吸。移除静态圆环和星光拖尾，触屏与减少动态效果时回退系统鼠标，桌面动效加载或暂停期间使用同款静态小圆点，滚轮与重新进入页面时立即恢复动效；失焦暂停、恢复焦点时按当前位置恢复，滚动时刷新磁吸目标，空闲停止渲染。

首页个人介绍下方移除重复社交链接，关于页仍提供联系入口。关于页志愿服务证书、抖音码、一万粉丝纪念图直接呈现，保留原图比例；不再用查看按钮或折叠隐藏。

升途教育使用用户提供的原始 Logo，替换原书本占位图标；仅在时间线方形容器中裁去上下留白。用户确认授课经历持续至今，中英文均为 2025.06 起至今。

ITSO 首页经历的“平台介绍”链接使用用户指定的 `https://ai.cuhk.edu.cn/chat/about`，个人 LinkedIn 社交入口继续保留。

Threadline 放在产品与工程实践首项，包含中英文摘要与详情页。依据 https://github.com/Doris619619/Threadline 及本地项目 README，介绍任务、习惯、时间规划与 Web/PWA/Windows 支持。详情展示原有 blue-light 演示截图，并提供仓库和 Windows 下载链接；未确认具体开始时间，因此不填日期。

作品列表取消标题上方重复的分类小字，直接从项目标题开始。状态与项目时间统一置于标题下方，使用 16px 字号；宽屏左右对齐，窄屏自然换行，不压缩字号。所属领域由左侧分组和项目标题表达。

页脚不展示 RSS 入口，订阅文件与自动发现元信息仍保留。关于页抖音介绍直接以账号名称开头，移除标题上方的装饰小字；中英文同步。

关于页使用 760px 阅读区域；校园生活采用左侧证书、右侧服务信息的紧凑图文行。开源创作的账号、简介、粉丝数在同一阅读列，两张原始图片并排等宽展示、保持完整比例，均可点击查看原图。手机缩小证书列与图片间距，取消装饰竖线和独立的大号粉丝数字。

本轮版式参考 [Brittany Chiang 当前个人站的 Projects 区](https://brittanychiang.com/#projects) 的相邻缩略图与内容排列，以及 [Bootstrap Media object](https://getbootstrap.com/docs/4.6/components/media-object/) 的图文组合方式；已实看桌面页面。仅借鉴布局结构，本地实现沿用本站内容、字体、色彩和静态生成机制。

本轮验证：360、390、430、768、1024、1440px，中英文与深浅主题共 24 组浏览器检查，无横向溢出或脚本异常；证书与两张创作图片均验证键盘打开原图。`lint`、JavaScript 语法检查、22 页静态站测试和动效测试通过。效果截图：[桌面深色](../artifacts/redesign/about-editorial-1440-dark.png)、[手机浅色](../artifacts/redesign/about-editorial-390-light.png)。
