# 个人站改版

## 页面与视觉

首页保持既有头像、居中大开场与动画布局，之后依次为自我介绍、GRACE 与 LLM × PCB 两项精选研究、获奖文章入口。项目总览每项只有名称、一句短说明，右侧展示简短状态，整行均可点击；删除索引编号、头部重复英文标签和列表成果段落。详情解释背景、贡献、成果和链接；不把所有信息堆进首页。

主导航：首页、作品、手记、轨迹、关于。荣誉是独立页面，从轨迹、关于、页脚与获奖文章可达。手机以非模态菜单提供全部主导航，Escape 关闭并把焦点归还菜单按钮。

内容区 1040px，文章 700px；正文 16px，文学原文 18px / 1.95 行高，项目标题桌面 22px、手机 20px。界面复用 LivePilot-v2 网页的 LiveNest Sans SC，保留大开场的原有布局。细线负责分组，玫瑰色用于强调和交互。取消旧项目卡片、大面积联系区和无功能分类栏。页面内容默认可见，不依赖滚动入场才能读到。

时间轴按提供资料的起始时间升序排列，保留“至今”状态，不推断结束日期。桌面 2024、2025、2026 横向年度导航定位到纵向事件，手机年度导航和事件均纵向排布。

## 内容与双语

中文默认，英文路径增加 `/en/`；语言切换保持当前页面与有效锚点，语言选择通过 URL 表达。主题跨页面保存，存储不可用时保持当页可用。

八项荣誉按学术与竞赛（3）、写作与影像（2）、体育（3）分组，各组按年月倒序。正式名称与奖项等级分别保存，不用奖杯装饰替代事实。已有证书作为独立链接，不作为文字背景。

《未选择的路》保留全部中文段落，中文写作日期 2025.01 与荣誉日期 2026.04 分开。英文页面只翻译标题、简介、导航与荣誉说明，正文标注为中文原作。全运会 81.50 小时志愿服务列为活动，不作为第九个奖项。

GRACE 标明 DAC 2026 录用和第 5 作者；LLM × PCB 标明进行中。RoboMaster 的 GitHub 链接准确标为个人主页。仅使用已有的项目描述和指标。

## 实现与兼容

构建时生成 22 个 HTML（11 个页面 × 2 种语言），以及 404、RSS、sitemap、robots.txt。页面正文、导航和 metadata 在静态 HTML 内，客户端脚本只增强交互。无新增后台服务或生产环境迁移。

旧文章查询参数优先于 `#top` 迁移；首页旧栏目、项目锚点分别指向新页面。新链接全部使用独立目录 URL，适配 GitHub Pages 直接刷新。更新导航和内容时必须同时检查双语链接、站点地图与 RSS。

现有 `typecheck` 命令改为真实 JavaScript 语法检查并明确说明不提供静态类型分析。测试自动构建再验证页面、链接、奖项关联和原文摘要。
